# ADR-0077: Hand-authored fixture data

## Metadata
- **Status:** `Final (scoped to Phase 9 only).`
- **Category:** Phase 9 — MVP Simulation Build
- **Decision Number:** #77
- **Date:** 2026-11-20

---

## Context
Needed demo data with a believable investigative narrative.

## Decision
Mock JSON fixtures are hand-authored, not generated by a script or LLM, including one deliberately flagged case and one deliberately clean case.

## Rationale
Guarantees narrative-quality, presentable demo data rather than plausible-but-flat generated placeholders.

## Alternatives Rejected
Script- or LLM-generated fixtures (faster to produce, but risks flat or incoherent demo narratives, and an LLM dependency contradicts this build's "no LLM" constraint even at the tooling level).
